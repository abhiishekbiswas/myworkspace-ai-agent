1. EXECUTIVE SUMMARY & OBJECTIVE
--------------------------------------------------------------------------------
This report provides an independent security, cost-safeguard, and architecture
verification of the Live AI Integration in My Workspace. It validates that the
hybrid AI assistant operates securely, respects user privacy, guarantees zero
paid API charges, protects against unauthorized or duplicate database writes, and
seamlessly defaults to local offline execution.

2. STRICT ZERO-COST & API BILLING SAFEGUARDS
--------------------------------------------------------------------------------
[CRITICAL REQUIREMENT: ZERO PAID API CALLS / ZERO BILLING CHARGES]

- Enforced Model Identifier: "gemini-3.8-flash"
  * Verification: Model name is strictly hardcoded in GeminiCloudEngine.kt.
  * Rejection of Paid Models: The system prohibits switching to paid models
    (such as gemini-4-argon, pro tiers, or high-compute endpoints).
- Official Free-Tier Compliance:
  * Uses Google AI Studio / Firebase AI Logic free tier ($0.00 / month).
  * No credit card or Blaze billing account is required.
  * Free tier boundaries: 15 Requests Per Minute (RPM), 1,500 Requests Per Day (RPD).
- HTTP 429 (RESOURCE_EXHAUSTED) Quota Handling:
  * When free quotas are reached, GeminiCloudEngine intercepts HTTP 429.
  * Instantly triggers zero-latency fallback to LocalCommandEngine.
  * Flags `isQuotaExhausted = true` and alerts the user via in-app banner without
    crashing, freezing, or attempting retry loops that could incur charges.

3. CREDENTIAL & SECRET MANAGEMENT AUDIT
--------------------------------------------------------------------------------
- Zero Hardcoded Keys:
  * Source code scan confirms NO API keys, client secrets, or private tokens are
    hardcoded in any Kotlin, Java, XML, or Gradle files.
  * All credentials are injected via `BuildConfig.GEMINI_API_KEY` through the
    AI Studio Secrets panel and `.env.example`.
- Git & Repo Hygiene:
  * `.env`, `debug.keystore`, and local secrets are excluded via `.gitignore`.
- Missing Key Graceful Handling:
  * If `BuildConfig.GEMINI_API_KEY` is empty or null, the system automatically
    disables cloud calls and redirects all queries to `LocalCommandEngine`
    without displaying cryptic errors to the user.

--------------------------------------------------------------------------------
4. DATABASE & TOOL EXECUTION SECURITY (ZERO RAW SQL)
--------------------------------------------------------------------------------
- Repository-Gated Tool Execution:
  * AI Tool calls dispatched by `AiToolRegistry` and `WorkspaceToolExecutor`
    run exclusively through type-safe Room DAOs and domain repositories:
    `WorkspaceRepository`, `NotesRepository`, and `AiMemoryRepository`.
  * The AI model NEVER has access to raw SQLite strings, `db.execSQL()`, or
    arbitrary database queries.
- SQL Injection Prevention:
  * All queries use Room parameterized queries (`@Query` with bounded arguments)
    and Kotlin Coroutine Flow pipelines.
- Scope-Limited Tool Permissions:
  * Only 11 whitelisted tools are exposed to the AI model:
    (getTodayTasks, getPendingTasks, getOverdueTasks, getTomorrowTasks,
     getProjectStatus, searchMemory, saveMemory, createTask, updateTask,
     completeTask, createReminder).
  * No external file deletion, package alteration, or system settings mutation
    tools exist in the AI registry.

--------------------------------------------------------------------------------
5. WORKFLOW INTEGRITY & BLOCKED TASK GUARDS
--------------------------------------------------------------------------------
- Dependency Engine Safety:
  * When `completeTask` is invoked by the AI, it evaluates `isTaskBlocked(taskId)`.
  * If a task has unfinished prerequisite tasks (Phase 3 Dependency Engine),
    the assistant CANNOT mark it completed automatically.
  * Instead, it returns `ToolExecutionResult.ConfirmationRequired` with a
    `PendingToolAction`, requiring explicit manual user consent in the UI.
- Idempotency & Duplicate Action Guard:
  * Every write tool invocation is hashed (`${toolCall.name}:${toolCall.arguments}`).
  * `HybridAiCoordinator` maintains an executed action signature set.
  * Prevents runaway LLM loops from duplicating tasks, reminders, or memories.

--------------------------------------------------------------------------------
6. DATA PRIVACY & USER CONTROL
--------------------------------------------------------------------------------
- Cloud AI Master Switch (User Toggle):
  * The user has direct UI control via `toggle_cloud_ai_button` in the TopAppBar.
  * When disabled by the user (`isCloudAiEnabled = false`), 100% of queries
    stay local on-device via `LocalCommandEngine`.
  * Zero network traffic is generated when the toggle is off.
- Local Storage Priority:
  * All user tasks, projects, notes, and chat messages reside in the local
    Room SQLite database (`WorkspaceDatabase.db`).
  * Only the prompt text necessary for reasoning is transmitted during online mode.

--------------------------------------------------------------------------------
7. NETWORK SECURITY & TIME-OUT BOUNDARIES
--------------------------------------------------------------------------------
- Transport Security:
  * All network communication is restricted to HTTPS / TLS 1.3 endpoints.
  * `ACCESS_NETWORK_STATE` and `INTERNET` are declared safely in AndroidManifest.xml.
- Strict Network Timeout:
  * Cloud requests enforce a strict 30-second client-side timeout (`withTimeout(30_000L)`).
  * Socket hanging or network dropouts trigger immediate offline fallback to
    `LocalCommandEngine`, ensuring uninterrupted user experience.

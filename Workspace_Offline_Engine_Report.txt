3. WORKSPACE TOOL EXECUTOR
--------------------------------------------------------------------------------
File: /app/src/main/java/com/example/ai/tools/WorkspaceToolExecutor.kt

Supported Actions & Signatures:
1. getTodayTasks() -> ToolExecutionResult
   - Filters tasks scheduled between start of day and end of day.
2. getPendingTasks() -> ToolExecutionResult
   - Retrieves all non-COMPLETED tasks sorted by priority (URGENT > HIGH > MEDIUM > LOW).
3. getOverdueTasks() -> ToolExecutionResult
   - Filters pending tasks whose due date timestamp is strictly before start of today.
4. getTomorrowTasks() -> ToolExecutionResult
   - Filters tasks scheduled for the calendar day of tomorrow.
5. getProjectStatus(projectName: String) -> ToolExecutionResult
   - Resolves target project with fuzzy matching and computes completed vs total task metrics.
6. searchMemory(query: String) -> ToolExecutionResult
   - Searches local persistent memories across fact text and category labels.
7. saveMemory(category: String, fact: String) -> ToolExecutionResult
   - Persists a remembered fact with timestamp into Room DB.
8. createTask(title: String, projectName: String?, priority: String, dueDate: Long?) -> ToolExecutionResult
   - Creates a new TaskEntity, associating it with the requested or default project.
9. updateTask(taskTitleOrId: String, newStatus: String?, newPriority: String?, progress: Double?) -> ToolExecutionResult
   - Modifies task properties after title/ID resolution and disambiguation.
10. completeTask(taskTitleOrId: String, forceIfBlocked: Boolean) -> ToolExecutionResult
   - Critical Safety Check: Evaluates `workspaceRepository.isTaskBlocked(taskId)`.
   - If blocked by uncompleted prerequisites and `forceIfBlocked == false`, returns
     `ToolExecutionResult.ConfirmationRequired` with `PendingToolAction` instead of completing.
11. createReminder(taskTitleOrId: String, dueDateMs: Long) -> ToolExecutionResult
   - Updates task dueDate and schedules an in-app reminder record.

Structured Result Types:
- ToolExecutionResult.Success(message: String, data: Any?)
- ToolExecutionResult.Error(message: String)
- ToolExecutionResult.ClarificationRequired(message: String, candidates: List<DisambiguationCandidate>)
- ToolExecutionResult.ConfirmationRequired(message: String, pendingAction: PendingToolAction)

4. LOCAL COMMAND ENGINE (MULTILINGUAL INTENT PARSER)
--------------------------------------------------------------------------------
File: /app/src/main/java/com/example/ai/engine/LocalCommandEngine.kt

Supports natural language commands across three linguistic modes:

A. Hindi (Devanagari):
- "आज कितने काम बाकी हैं?" -> CommandIntent.GetTodayTasks
- "पेंडिंग काम दिखाओ" / "अधूरे काम बताओ" -> CommandIntent.GetPendingTasks
- "कल क्या करना है?" -> CommandIntent.GetTomorrowTasks
- "Design review काम पूरा हो गया" -> CommandIntent.CompleteTask("Design review")
- "मैंने क्या याद रखने को कहा था?" -> CommandIntent.SearchMemory("")
- "याद रखना कि क्लाइंट मीटिंग शुक्रवार को है" -> CommandIntent.SaveMemory("General", ...)

B. Hinglish (Latinized Hindi-English blend):
- "Aaj ke pending tasks batao" -> CommandIntent.GetPendingTasks
- "Electricity bill ko complete mark karo" -> CommandIntent.CompleteTask("Electricity bill")
- "Project Alpha ka status kya hai?" -> CommandIntent.GetProjectStatus("Alpha")
- "Yaad rakhna mujhe weekly reports pasand hain" -> CommandIntent.SaveMemory("Preference", ...)
- "Maine kya yaad rakhne ko bola tha?" -> CommandIntent.SearchMemory("")

C. English:
- "What are my tasks for today?" -> CommandIntent.GetTodayTasks
- "Show my overdue tasks" -> CommandIntent.GetOverdueTasks
- "Create a task called Submit GST return" -> CommandIntent.CreateTask("Submit GST return")
- "Mark Electricity Bill as done" -> CommandIntent.CompleteTask("Electricity Bill")
- "Remember that client meeting is on Friday" -> CommandIntent.SaveMemory("General", ...)
- "What did I ask you to remember?" -> CommandIntent.SearchMemory("")

Fallback & Help:
- Unrecognized queries trigger `CommandIntent.Unknown` with helpful suggestions
  and usage examples in conversational format.

5. REAL REMINDER & ALARM LIMITATION AUDIT
--------------------------------------------------------------------------------
- Current Implementation:
  `createReminder` updates the task's `dueDate` and records the timestamp in
  the database. The tasks appear in calendar views, today/tomorrow filters,
  and deadline queries.
- Device OS Limitations:
  In offline container environments, exact system push notifications via
  `AlarmManager.setExactAndAllowWhileIdle` require runtime `POST_NOTIFICATIONS`
  and `SCHEDULE_EXACT_ALARM` permissions. The tool executor notes this
  limitation gracefully and maintains reliable in-app scheduling.

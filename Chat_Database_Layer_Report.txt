3. ENTITY & DAO IMPLEMENTATION DETAILS
--------------------------------------------------------------------------------

3.1 Room Entities:
• conversations:
  - Primary Key: id (UUID String)
  - Fields: title, isGroup, avatarUrl, avatarColor, isPinned, isMuted, unreadCount,
    lastMessageId, lastMessageText, lastMessageTimestamp, createdAt, updatedAt
  - Indexes: index_conversations_lastMessageTimestamp, index_conversations_isPinned

• chat_messages:
  - Primary Key: id (UUID String)
  - Foreign Key: conversationId -> conversations(id) ON DELETE CASCADE
  - Fields: senderId, senderName, text, messageType, status, replyToMessageId,
    replyToSenderName, replyToText, isStarred, createdAt, updatedAt
  - Indexes: index_chat_messages_conversationId, index_chat_messages_createdAt,
    index_chat_messages_replyToMessageId

• message_attachments:
  - Primary Key: id (UUID String)
  - Foreign Key: messageId -> chat_messages(id) ON DELETE CASCADE
  - Fields: fileName, fileUri, fileType, fileSizeBytes, thumbnailUri, durationMs, createdAt
  - Index: index_message_attachments_messageId

• contacts:
  - Primary Key: id (UUID String)
  - Fields: name, role, email, phoneNumber, avatarColor, initials, statusBio,
    isDemo, lastActiveTimestamp, createdAt
  - Indexes: index_contacts_name, index_contacts_isDemo

3.2 ChatDao Capabilities:
• Reactive Flows:
  - getAllConversations(): Flow<List<ConversationEntity>>
  - getConversationById(id: String): Flow<ConversationEntity?>
  - getMessagesForConversation(conversationId: String): Flow<List<ChatMessageEntity>>
  - searchMessages(query: String): Flow<List<ChatMessageEntity>>
  - searchMessagesInConversation(conversationId: String, query: String): Flow<List<ChatMessageEntity>>
  - getAttachmentsForMessage(messageId: String): Flow<List<MessageAttachmentEntity>>
  - getAllContacts(): Flow<List<ContactEntity>>
  - searchContacts(query: String): Flow<List<ContactEntity>>
• Atomic Transactions:
  - insertMessageAndUpdateConversation(message: ChatMessageEntity):
    Inserts chat message and updates conversation's lastMessageId, lastMessageText,
    and lastMessageTimestamp atomically within a single SQLite transaction.

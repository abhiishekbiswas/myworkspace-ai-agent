3. DOMAIN MODEL DETAILS
--------------------------------------------------------------------------------
• MessageStatus:
  - LOCAL_PENDING: Message created locally, awaiting local database write.
  - LOCAL_STORED: Message stored locally on device.
  - LOCAL_SENT: Message sent locally by user.
  - LOCAL_READ: Message viewed locally by user.
  (Zero fake online transmission or external server claims).

• MessageType:
  - TEXT: Standard textual content.
  - IMAGE: Photo / image media.
  - DOCUMENT: File attachment (PDF, Docs).
  - AUDIO: Voice note or audio recording.

• AttachmentType:
  - Parsed automatically from MIME types (e.g. image/* -> IMAGE, audio/* -> AUDIO).

• Conversation:
  - id, title, isGroup, avatarUrl, avatarColor, isPinned, isMuted, unreadCount,
    lastMessageId, lastMessageText, lastMessageTimestamp, createdAt, updatedAt.

• ChatMessage:
  - id, conversationId, senderId, senderName, text, messageType, status,
    replyToMessageId, replyToSenderName, replyToText, isStarred, createdAt, updatedAt,
    isOutgoing (senderId == "me").

• MessageAttachment:
  - id, messageId, fileName, fileUri, fileType, fileSizeBytes, thumbnailUri, durationMs, createdAt.

• Contact:
  - id, name, role, email, phoneNumber, avatarColor, initials, statusBio,
    isDemo (boolean flag), lastActiveTimestamp, createdAt.


4. REPOSITORY IMPLEMENTATION DETAILS (ChatRepository.kt)
--------------------------------------------------------------------------------
• Conversations:
  - allConversations: Flow<List<ConversationEntity>>
  - getConversationById(id: String): Flow<ConversationEntity?>
  - getConversationByIdOnce(id: String): ConversationEntity?
  - createConversation(title, isGroup, avatarColor, contactId):
    Validates non-blank title, checks for existing 1-on-1 duplicate conversations,
    generates UUID and current timestamp, inserts into Room.
  - setConversationPinned(id, isPinned): Updates isPinned and updatedAt.
  - setConversationMuted(id, isMuted): Updates isMuted and updatedAt.
  - resetUnreadCount(id): Resets unreadCount to 0.
  - deleteConversation(id): Deletes conversation (cascades to messages & attachments).
  - searchConversations(query): Reactive search filtering by title and lastMessageText.

• Messages:
  - getMessagesForConversation(conversationId): Flow ordered chronologically (createdAt ASC).
  - sendLocalTextMessage(conversationId, text, senderId, senderName, replyToMessageId):
    Validates non-blank text, verifies conversation exists, resolves reply quotes,
    sets status to LOCAL_SENT, and executes atomic transaction updating conversation
    preview and timestamp.
  - editMessage(messageId, newText): Validates non-blank text, updates message and
    conversation preview if it was the last message.
  - deleteLocalMessage(messageId): Deletes message (cascades to attachments).
  - replyToMessage(conversationId, originalMessageId, replyText, senderId, senderName):
    Verifies original message exists and links quote metadata into new message.
  - setMessageStarred(messageId, isStarred): Updates star state.
  - searchMessages(query) & searchMessagesInConversation(conversationId, query):
    Reactive text search.
  - markMessagesAsLocallyRead(conversationId): Resets unread count and marks
    unread messages as LOCAL_READ.

• Contacts:
  - allContacts: Flow<List<ContactEntity>>
  - searchContacts(query): Reactive search across name and role.
  - saveContact(contact): Validates non-blank name, preserves isDemo flag.
  - deleteContact(id): Deletes contact record.

• Attachments:
  - saveAttachmentMetadata(messageId, fileName, fileUri, fileType, ...):
    Validates parent message exists and persists attachment metadata.
  - getAttachmentsForMessage(messageId): Flow of attachments for a message.
  - deleteAttachment(attachmentId): Deletes attachment record.

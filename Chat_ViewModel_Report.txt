3. VIEWMODEL STATE ARCHITECTURE
--------------------------------------------------------------------------------

3.1 Chats Home Reactive State:
• allConversations: StateFlow<List<ConversationEntity>>
  - Directly observes IChatRepository.allConversations.
• allContacts: StateFlow<List<ContactEntity>>
  - Directly observes IChatRepository.allContacts.
• searchQuery: StateFlow<String>
  - User's search query across conversation titles and message previews.
• selectedFilter: StateFlow<ChatFilter>
  - Active filter tab: ALL, UNREAD, PINNED, DIRECT, CHANNELS.
• filteredConversations: StateFlow<List<ConversationEntity>>
  - Reactive combine(allConversations, searchQuery, selectedFilter) emitting
    filtered and sorted conversations.
• unreadConversationsCount: StateFlow<Int>
  - Reactive count of conversations with unreadCount > 0.
• isLoading: StateFlow<Boolean>
• errorMessage: StateFlow<String?>

3.2 Conversation Thread Reactive State:
• selectedConversationId: StateFlow<String?>
  - Currently active conversation ID (null when on Chats Home list).
• selectedConversation: StateFlow<ConversationEntity?>
  - Reactive combine(allConversations, selectedConversationId) resolving
    active conversation metadata.
• currentMessages: StateFlow<List<ChatMessageEntity>>
  - FlatMapLatest on selectedConversationId observing messages in chronological order.
• inConversationSearchQuery: StateFlow<String>
• displayedMessages: StateFlow<List<ChatMessageEntity>>
  - Combines currentMessages and inConversationSearchQuery for live search.
• draftMessageText: StateFlow<String>
  - Local input field buffer.
• replyingToMessage: StateFlow<ChatMessageEntity?>
  - Active quoted reply target (null when not replying).
• selectedMessageForAction: StateFlow<ChatMessageEntity?>
  - Long-pressed message target for context actions.
